💪 BMI Tracker App

A BMI (Body Mass Index) Tracker Android application built using **Kotlin** and **Jetpack Compose**. The app helps users calculate their BMI based on height and weight and understand their BMI category through a simple, user-friendly interface.

✨ Features

- 📏 Enter height and weight
- ⚖️ Calculate Body Mass Index (BMI)
- 📊 Display BMI results and category
- 🎨 Clean and modern user interface
- 📱 Responsive UI built with Jetpack Compose
- ⚡ Simple and easy-to-use experience

🛠️ Tech Stack

- Language: Kotlin
- UI Framework: Jetpack Compose
- Platform: Android
- IDE: Android Studio

🧮 BMI Formula

BMI is calculated using the following formula:

BMI = Weight (kg) / Height (m)²**

The calculated value can be used to identify a general BMI category. BMI is a screening measure and does not independently determine a person's health.
